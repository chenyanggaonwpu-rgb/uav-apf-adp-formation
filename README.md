## 实际控制顺序

1. 分层全局规划提供航点；水平 V 形动态参考和 APF 共同生成五机基础加速度。
2. 同一个冻结 Actor 通过监督器介入长机局部脱困，输出一个三维临时航点。僚机保持编队、APF 和机间作用。
3. 加速度指令按模长限制到 3 m/s²。启用安全层时，执行预测修正和共同制动轨迹检查。
4. 真实质点系统总是向前积分。外部加速度在指令限幅后叠加；位置噪声进入反馈、监督器历史和安全计算。
5. 用真实状态独立检查整段运动的障碍距离、机间距离和工作空间边界。

Actor 的 6467 个参数在全地图共享。每次任务重置监督器状态、轨迹和规划缓存；模型参数保持原值。默认运行不调用旧的残差 Actor、Critic 或在线学习。

Actor 每 0.2 秒检查介入条件，物理积分步长为 0.05 秒。持续停滞后才调用网络；普通地图可以成功完成且 Actor 调用数为 0。这表示监督器没有请求接管。逐任务日志分别记录模型已加载、调用次数和介入次数。

## 复现实验

在 MATLAB 中运行：

```matlab
addpath('experiments3d/unified_actor_20261029');
output=run_all_unified();
```

目录内的 `catalogue.mat` 包含全部地图与已声明任务。复现不依赖本机此前的旧 results 目录。要运行一个地图：

```matlab
addpath('config','src','src3d');
p=default_params3d();
p.sceneId='S8_window';
r=main3d(p);
disp(r.model)
disp(r.controller)
```

正式重验计划共 3840 次：原安全层地图 154×4、APF 动态场景 50×4、抗扰条件 12×38×4、五机接入 128×2、全局规划与脱困六组合 144×6、单机留出集 40×2。Actor 关闭组和规则组仅作显式消融对照。噪声每轴标准差 0、0.02、0.05、0.10 m，外扰幅值 0.10、0.30、0.50、1.00 m/s²，方向为 ±Y、±Z，保持 2 秒；联合条件为 0.02 m 和 0.30 m/s²。

旧版 R/S 结果属于原残差 ADP 实现，不能用来评价此冻结 Actor。重验汇总和修订报告随后以同一版本的证据目录交付。历史 2D 和未知地图开发资料保持独立。
