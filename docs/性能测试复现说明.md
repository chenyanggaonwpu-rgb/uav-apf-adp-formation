# v1.0.0 与 v1.1.0 配对性能测试复现

此目录包含原版源码快照 `baseline_v1.0.0_source_20260919.zip`、逐 seed 原始统计
`benchmark_baseline.csv` / `benchmark_improved.csv`，以及图文 PDF 报告。原版快照
在修改源码之前保存，不含自动生成的图片和运行时缓存。

测试采用 MATLAB R2024a，seed 1–100，均使用各版本 `default_params` 的算法参数。
共同的场景配置是 5 架二维质点、8 个静态圆形障碍物、`dt=0.05 s`、`Tmax=500 s`。
两版的障碍生成函数和相关场景参数未改变，并逐 seed 检查了 100 组圆心与半径，
数值完全一致。结果按 seed 配对，不按随机生成的另一组障碍场景比较。

`benchmark_suite.m` 在项目 `tests/` 中。将 ZIP 解压到一个独立文件夹，在 MATLAB 中：

```matlab
addpath('F:\UAV project\UAV_APF_ADP_Formation\tests');
benchmark_suite('解压后的原版目录', '基线结果.mat', 1, 100);
benchmark_suite('F:\UAV project\UAV_APF_ADP_Formation', '新版结果.mat', 1, 100);
```

该函数同时生成同名 CSV 与 MAT。`success` 是满足项目完整成功条件的场景数；
`reason` 区分 success、collision、timeout。`time` 是任务仿真秒数，不是计算机
运行耗时；`wallSeconds` 才是本机运行耗时，不应跨设备直接比较。

报告中完成时间的中位数和 P90，仅在两版均成功的 95 个配对 seed 上计算，以避免
把碰撞时的提前终止时间误当成高性能。CSV 中的最小净空是采样时刻的位置统计，
不是连续安全保证。seed 1–20 是修改前已知的失败排查样本；21–100 是修改后新增
的检验样本。100/100 只描述这些场景，不表示任意障碍布局或真实无人机均保证成功。
