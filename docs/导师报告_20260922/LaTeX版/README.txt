编译说明
========

1. 使用 XeLaTeX 编译 main.tex。
2. 推荐命令：latexmk -xelatex main.tex
3. main.tex 与 assets 文件夹必须保持同级。
4. 报告使用 Windows 字体：Times New Roman、宋体（SimSun）和微软雅黑。
5. 已在 TeX Live 2025 下完成编译和逐页检查。

文件说明
========

- main.tex：报告源文件
- assets：五张矢量 PDF 图表
- 无人机编队智能避障项目技术报告_V1.1.1_LaTeX.pdf：编译后的正式报告
- 附件_Seed1_200指标.csv：报告统计数据
