## 运行与失败释义

`safety_unresolved`：预测安全控制在现有迭代预算内未找到安全指令，任务终止；`timeout`：120 s内未完成终端保持；`replan_failed`：停滞后的重规划未返回路线。失败仍有正常场景与独立见证，因此不能归为起始位置占障碍的无效样本。

- generate 阶段总墙钟时间（含MATLAB启动/退出及并行开销）：8.05 min。
- flight 阶段总墙钟时间（含MATLAB启动/退出及并行开销）：68.79 min。
- audit 阶段总墙钟时间（含MATLAB启动/退出及并行开销）：2.73 min。

成功任务的仿真时间中位数 32.90 s，P95 48.00 s，最大值 113.70 s。墙钟运行时间不作为机载实时性证明。
