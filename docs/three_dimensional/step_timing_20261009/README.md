## 计时范围和计算条件

计时从run_simulation3d.m第84行的tic到第218行的toc。一步覆盖五架无人机的参考生成、控制、ADP更新、安全检查、仿真推进、记录，以及当步触发的重规划和终端规划。初始规划在循环之前另计。

原始实验为六个并行MATLAB进程，每进程单计算线程。统计反映本机该批并行仿真的墙钟耗时，尚不是单进程独占条件下的时限测量，更不是硬实时上界证明。仿真步长dt=0.05 s不能直接证明计算可在50 ms内完成；同步仿真的成功率也没有验证真实飞行中超时引起的控制延迟。

P95/P99/P99.9对全部步骤合并排序，采用最近秩；中位数使用MATLAB median。超时定义严格大于50 ms，比例按总步数加权，未平均每个seed的比例。

## 对实时性改进的含义

最慢一步中约12.528秒用于终端路线规划。若要求严格50 ms控制周期，应将终端规划和重规划从同步控制循环分离，配合预计算、缓存和明确的时限与回退策略；改造后需要单进程独占测试和模块计时，评估常规控制与安全层的剩余峰值。
