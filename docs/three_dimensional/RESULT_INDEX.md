## 复现入口

在项目根目录启动 MATLAB R2024a，先 `addpath('experiments3d')`，执行 `run_study3d('full')` 可重新生成独立结果目录。`test_3d` 与 `run_all_tests` 分别完成三维和历史二维回归。完成后用 `python experiments3d/analyze_study3d.py <结果目录>` 生成统计 JSON；`render_study_evidence(<结果目录>)` 再生图。图表和报告的可编辑源为 `TECHNICAL_REPORT.md`、`build_report_pdf.py`、`flow.mmd` 和各 MATLAB 绘图脚本。运行期间不要同时运行其它高负载任务，以减少周期尾部计时干扰。

本次在受限执行环境中，MATLAB 默认偏好目录无访问权限；将 `MATLAB_PREFDIR` 指向项目 `.runtime/matlab_prefs_3d` 后测试和绘图成功。普通本机 MATLAB 环境无需此设置。
