| 项目 | 已实现 |
|---|---|

这些结果用于验证新规则与代码接入，不构成正式成功率估计。接受率约 14.81% 是这 81 张功能验证候选上的比例；接受分布会向满足起终点、通道和保守见证条件的地图倾斜。不能把三次成功写成正常环境成功率 100%，也不能与旧无约束 60.5% 或旧条件子集 92% 作同分布对照。

完整正式结果位于 `F:\UAV project\UAV_APF_ADP_Formation\results\normal_scene_v2.3.3_20261009_validation_final`，包含 12 个冻结地图 MAT（含候选）、三份完整任务 MAT、CSV/JSON 生成收据和公开入口图。紧凑结果、日志、源码 SHA 与本轮源文件快照在当前文档目录。

独立见证不调用现有有限高度层规划器或控制器。固定 V 形、六邻接、2 m 网格、40000 节点预算都是充分条件方法的局限；未找到见证时记录“尚未证实”，不宣称物理无解。见证开销是离线审核开销，不是飞行实时开销。当前模型从空中开始，未新增地面升空、噪声、外扰或真实机体模型验证。
