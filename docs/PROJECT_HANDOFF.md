## 3. 项目原理与代码入口

项目使用MATLAB R2024a，在80×80 m二维工作空间中仿真5架单位质量质点无人机和静态圆障碍。1号机为长机，其余为僚机。主要控制链是：

1. 随机生成障碍，并对布局、起终区域与可通行栅格进行筛选。
2. 长机以膨胀栅格最短路及视线简化形成航点，配合APF和停滞逃逸导航。
3. 僚机沿长机历史轨迹取滞后点并叠加横向偏移，再对参考点做避障修正。
4. 基础APF/编队控制叠加Actor–Critic ADP加速度修正，经限幅、预测安全修正后积分。
5. 到目标附近后使用固定航向V形作为归队参考基准；参考点仍可能因障碍被调整。完整成功条件连续满足后结束。

| `marginObs` | 障碍物边缘间距下限1 m |
| `formSpacing` / `formWing` | 纵向逐排间距3 m / 横向逐排偏移2.5 m（第二排横向5 m） |
| `pathGridResolution` | 1 m |
| `pathClearance` | 长机栅格膨胀净空4.2 m |
| `obsSafe` / `uavSafe` | 障碍安全距0.6 m / 机间安全距1 m |
| `desiredClear` | 参考点对障碍表面的净空4 m |
| `goalTol` / `formTol` / `vTol` | 1 m / 1 m / 0.25 m/s |
| `holdDuration` | 成功条件连续保持1 s |
| 生成重试预算 | 最多60次整组布局；每个障碍最多300次放置尝试 |
| ADP | 开启；增益0.5，修正加速度幅值上限0.8 |

必须区分以下量：

- **4.2 m**：长机栅格膨胀参数。一般简化线段检查净空为3.4 m，端点连接检查为0.75 m；4.2不是实际飞行全程最小净空保证。
- **5.6 m**：场景生成筛选的有效净空，公式为 `max(pathClearance, 最大编队横向偏移 + obsSafe) = max(4.2,5.0+0.6)`。因此只把4.2继续调小，不会让默认五机的生成筛选净空随之降低。
- **1.9 m**：僚机归队时的栅格规划净空，是另一环节。
- `corridorBand=B`表示左右各B米；超出场地时圆心会被截回允许范围，不能把B=50理解为实际障碍在100 m宽无限带中均匀分布。
- 任务的队形误差是各僚机到**动态且经避障修正的参考位置**的最大距离，不是固定刚性V形几何误差。
- 成功要求：长机目标误差≤1 m、最大僚机参考误差≤1 m、全机速度≤0.25 m/s连续保持1 s，且全程无碰撞、未超时。

### 统一统计口径

- 条件飞行成功率分母：success + collision + timeout + invalid_state；不含generation_failed或execution_error。
- 整体成功比例分母：该组已执行计划seed数；生成失败计为未成功。
- 执行异常出现时，该组推断性成功率与整体成功比例记NA，不能当成正常飞行失败。
- 时间、路径系数、队形RMS的汇总只采用成功样本。路径系数=长机累计路径/起终点直线距离。
- 队形RMS先对一次运行中每步最大僚机参考误差作时间均方根，再对成功seed取平均。
- Wilson区间是逐组95%区间，不是125组的同时区间；不同参数下同seed不保证同一地图，不能直接宣称严格配对。
- `run_batch`以全部请求seed为成功率分母，包含异常；与上述条件飞行成功率不同。
- 200 seed/组用于现有扫描，不足以可靠排序99.5%与100%的细微差异。已有4.2 m默认值不应被描述为经本轮环境扫描证明的全局最优膨胀值。
