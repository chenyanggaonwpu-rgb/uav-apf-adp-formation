更新：2026-10-09。数值配置为 `config/default_params3d.m`；默认演示 `S8_window`，默认随机入口使用正常场景生成器。当前发布集中整理源码、说明、2000次任务结果与逐步耗时，没有修改控制器、参数或成功判据。

## 核心能力

| 模块 | 职责 | 主入口 |
|---|---|---|
| 场景与几何 | 球、有限圆柱、箱体；完整候选抽样与正常环境条件检查 | `scenario3d`, `normal_scene3d`, `obstacle_distance3d` |
| 高度选择 | 基础五层；无路线时对缺层可用区间补中点，最多新增8层 | `adaptive_height_layers3d`, `available_height_intervals3d` |
| 有限层规划 | 层内八邻接、相邻层竖直连接、连续净空检查、距离与升降代价 | `plan_layers3d` |
| 编队参考 | 水平历史弧长滞后、V形偏移、同步高度、终端过渡及避障投影 | `formation_reference3d` |
| 基础控制 | 航点引导、参考跟踪、障碍斥力及机间避让 | `control3d`, `apf_repulsion3d` |
| ADP | 六维特征、三轴修正、全队共享24个学习权重 | `adp_features3d`, `adp_update3d` |
| 安全与推进 | 最多五轮预测修正；实际状态连续安全评价；质点推进 | `resolve_safety3d`, `check_swept3d`, `motion_step3d` |
| 任务与记录 | 初始/事件/终端规划、连续成功保持、失败分类、MAT/CSV和图 | `run_simulation3d`, `main3d` |

各模块具有独立函数入口。`run_simulation3d`集中编排状态机，参考生成含避障修正，安全层可能覆盖控制输出；这些职责交互需要结合日志解释。ADP结构与代价可以解释，尚未证明全局最优性或所有场景的稳定/安全。

## 参数

五机；空间80×80×30 m；初始高度10 m且零速度；基础层5/10/15/20/25 m；临时层最多8层；水平栅格1 m；规划/参考余量1.2/4.0 m；方向余量关闭；硬障碍/机间阈值0.6/1.0 m；速度/命令加速度上限3/3；dt=0.05 s，Tmax=120 s；默认无噪声与外扰。
