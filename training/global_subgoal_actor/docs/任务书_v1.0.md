# 全局子目标规划Actor训练与验收交接文档

乙方技术任务书  版本1.0  2026年11月15日

发出方：甲方。接收方：乙方研发与测试团队。乙方已获得甲方GitHub项目地址，本文件明确应训练的策略、验收口径、对照与消融方法，以及应交付的复现证据。

**交付目标：训练一个全程承担全局路线选择的Actor。在已知三维全图的障碍环境中，Actor从任务起点持续输出三维子目标，由原有APF、编队与安全控制执行，使五架无人机在120秒内安全到达目标区域并稳定成队。**

评判顺序为安全五机完成、逐场景可靠性，再看耗时、路径、绕圈与控制平滑性。训练回报、损失下降和演示视频均不能替代固定数据集上的闭环评估。

## 1 任务范围与工程基线

### 1.1 乙方需要完成的工作

1. 基于已提供仓库，定位全局子目标规划工程，完成训练、原生五机闭环接入、固定验证与独立测试。
2. 交付一个经过验证集选定并冻结的主Actor，以及可恢复训练的完整检查点。保留训练来源与模型SHA256，不以最后一次保存的权重自动作为最优模型。
3. 完成本文要求的基线对照与组件消融，提供全部运行的明细、统计结果、失败案例和一键复现说明。

开工回执须记录仓库地址、commit SHA、实验目录的仓库内相对路径、运行环境和原生worker哈希。若仓库有多个实验目录，以 `actor_schema=6`、`action_semantics=normalized_global_subgoal_xyz`、`task_protocol=global_subgoal_v1` 定位本任务；旧的卡住后短时脱困Actor属于对照方法。

训练工作使用独立分支、实验目录和run。涉及算法、奖励、原生程序或配置变化时，建立新run并记录迁移；保持原有模型和实验结果可追溯。甲方本机新增文件、临时文件、缓存与检查点统一放F盘；乙方在自己的机器上使用独立数据盘并记录位置。

### 1.2 固定的系统边界

| 项目 | 本任务要求 |

## 2 Actor结构与闭环接口

### 2.1 输入与网络

Actor隐藏层固定为 **512 → 512 → 256 → 256**，保留LayerNorm与ReLU，输入3340维，输出三维归一化全局子目标。训练时可以保留随机策略的均值与标准差输出头，正式评估使用确定性均值。

| 输入部分 | 维度 | 内容与约束 |
|---|---:|---|
| 局部历史 | 2048 | 16帧×128维，历史步距2，按旧到新排列；保持原观察语义与缩放 |
| 当前绝对位置 | 3 | 测量的leader位置，按120、120、30米缩放 |
| 全图静态信息 | 1289 | 工作空间边界6维、最终目标3维、128个障碍各10维 |
| 总输入 | 3340 | 全图包括远处和遮挡后的障碍，不以局部传感范围裁剪 |

障碍token含存在标记、box/cylinder/sphere类型、中心xyz及尺寸xyz。最多128个障碍，超容量应报错，不得静默丢弃。排序依据最终float32值，保证Python与MATLAB一致。三维动作从[-1,1]线性映射到当前工作空间坐标，动作语义和导出schema均须写入模型元数据。

若改动Critic、采样方法或优化策略，应单独记录并与SAC基线比较；不得把Actor改成不同宽度、不同动作含义的网络后沿用本任务名义。

### 2.2 决策与执行

常规子目标决策间隔为1.6秒；到达、停滞等事件允许提前重选，最短间隔0.4秒。两个决策之间由底层控制持续跟踪，不把每个0.2秒观察帧误作新动作。

子目标可因障碍内部、过近或不可行而投影。每次记录原始动作、请求坐标、执行坐标、投影距离、投影方式及重选原因。安全层与投影的干预量须进入评估，便于区分策略本身的质量与下层补救作用。

全程候选不得套用旧30秒或10秒接管预算，不得在超时后偷偷交回规则leader路线。运行日志须能验证 `leader_rule_planner_calls=0`，并记录是否发生预算强制交接。

## 3 奖励与训练记录

### 3.1 以完整任务形成信用分配

一个episode是一段完整五机任务。每条转移从一次真实子目标决策延续到下一次决策或任务终止，累计覆盖其中全部0.05秒物理区间；最后的终端编队收敛也计入最后一条转移。正常换子目标不置done，整段任务只出现一个terminal，最终结果只结算一次。

时间折扣使用实际持续时间，基线实现为 `discount = gamma ** (elapsed / 1.6)`。距离场势能使用 `potential = discount * phi_next - phi_current`，其中势能为到最终目标的地图可达距离负值除以8，终端下一状态势能归零。距离场使用三线性插值，以提供连续进度反馈。

不单独奖励“到达Actor自己选出的容易子目标”。势能衡量最终任务进展，结合真实耗时、重访与停滞成本，允许绕障时暂时远离终点的欧氏距离。地图距离场只能提供标量奖励，不能将路径、见证航点或专家动作作为网络输入和监督标签。

### 3.2 当前奖励基准

下表是现有实现的复现起点。乙方可在训练集和验证集上优化，但须保留该基准、单独标识改动，并在最终测试前冻结完整奖励配置。

| 项目 | 当前基准 | 实施口径 |
|---|---|---|
| 最终结果 | 安全五机成功+60；普通失败-30；不安全或严重碰撞-80 | 只在最终terminal结算一次 |
| 连续进度 | 地图距离场除以8，按实际时间折扣形成势能差 | 对最终目标计进度，不按自选子目标计成功 |
| 耗时与停滞 | 耗时0.1/秒；停滞0.3/秒 | 逐物理区间积分，停滞判据固定并记录 |
| 实际行程 | leader为0.01/米；五机总行程为0.001/米 | 用真实轨迹计算，避免测量噪声虚增路程 |
| 重访与重复子目标 | 重访系数2；重复子目标0.1/次 | 3米栅格、间隔至少8秒的返回事件；dt=0.05时每个触发物理步罚0.1，不对持续占据同一格反复算返回 |
| 接近安全边界 | 距安全边界外1米内二次惩罚，每类系数1/秒 | 障碍、机间、工作空间三类分别积分；硬安全层仍保留 |
| 其余代价 | 控制量平方积分系数0.0001；动作变化平方0.01；安全干预0.15/秒；投影0.005/米 | 具体计算位置、单位、积分方式随配置与代码共同交付 |

重访的“20倍”是系数2相对旧基准0.1的记录，不要在系数2之外再乘20或1000。接近边界成本与硬安全约束分开：去掉软成本的消融仍保留硬安全层。

### 3.3 训练可观察性

每个run至少记录真实物理步数、飞行次数、唯一地图几何数、Replay规模、Actor与Critic更新数、实际执行与回退后保留的更新数、BC与专家查询数，以及各奖励分量。

Critic的训练误差与保留TRAIN地图探针误差分开报告，并按普通、成功、超时、不安全结局分层。保留TRAIN探针不能参与梯度训练；验证集和测试集也不能进入Replay。需记录Actor冻结时长、解除冻结依据、过大更新拒绝与验证回退原因。

训练地图须覆盖方向、密度、噪声与地形变化，持续补充未见几何，Replay避免被少量重复地图淹没。课程未达标必须保留未掌握记录；可调整采样优先级继续训练，不能改小验收阈值来伪造晋级。训练中止时须提交原因与恢复状态，不能把停止运行写成训练完成。

## 5 Actor评价标准

### 5.1 安全五机成功的定义

一次任务只有同时满足以下条件才计为安全五机成功：120秒内满足原生终端保持条件，整段轨迹未违反障碍距离、机间距离与工作空间边界，且仿真和独立审计通过。leader单独到达不计为五机成功。

| 冻结参数 | 当前原生基准 |
|---|---:|
| leader到最终目标距离goalTol | 不大于1.0米 |
| 原生最大编队位置误差formTol | 不大于1.0米 |
| 五机最大速度vTol | 不大于0.25米/秒 |
| 连续满足终端条件holdDuration | 至少1.0秒，并满足原终端保持及参考点可行条件 |
| 障碍安全距离obsSafe | 全程严格大于0.6米 |
| 机间安全距离uavSafe | 全程严格大于1.0米 |

阈值随基线参数快照冻结，不能为了提分放宽。安全性按五机完整轨迹及物理区间审计；安全层发生干预本身不等于任务违规，两者分别统计。严重碰撞与越界按原生critical定义另计，须交付独立复算结果。

### 5.2 必须报告的指标

| 指标 | 统计口径 |
|---|---|
| 安全五机完成率 | 安全且五机成功任务数除以全部预定任务数，同时报告分子和分母 |
| 不安全与严重碰撞 | 分别报告任务数、比例、触发类型及具体case ID |
| 逐场景表现 | 16类分别报告安全成功数、不安全数，单列干净和扰动条件 |
| 失败计120秒均时 | 安全成功用真实任务时长，其余任务均计120秒；不能只平均成功任务 |
| 路径与效率 | leader及五机总路程；同时给出全样本与同图双成功子集，注明样本数 |
| 停滞与绕圈 | 停滞秒数、重访事件/计费时长、重复子目标数、有效最终任务进度 |
| 安全层依赖 | 干预步比例、投影次数和距离、近边界停留时长、最小及低分位安全裕度 |
| 编队与控制质量 | 终端误差、编队误差统计、速度/加速度与控制变化，避免只靠强制制动保安全 |
| 推理开销 | 同硬件同线程、batch=1热身后，报告前向、编码和投影的P50/P95/P99，以及超过0.4秒的次数 |

技术异常须按原模型、原case与原种子补跑，并保留异常记录。不能删掉候选失败任务、只展示成功轨迹，或用更短的任务时间降低耗时统计。

### 5.3 主模型验收与选模

**最低性能目标：** 最终主模型在独立TEST512上安全五机完成率至少85%，即至少436/512；每类至少70%，即每类至少23/32。严重碰撞任务为0，不安全任务数不得高于三个主要对照中的最小值。

**相对优势要求：** 对全图规则规划、局部规则和V2分别做同图安全成功配对比较。报告救回、退步与净增任务数，按场景分层进行至少10000次配对地图bootstrap；成功率差95%区间下界大于0，三项精确McNemar检验经Holm校正后均小于0.05，才支持对这些主要对照的优势结论。

85%是最低目标，不等于“最强”。若全图规则规划在相同任务中更高，仅达到85%仍不满足相对优势要求。工程可运行、最低性能达标、相对优势成立须分别给出结论，未达哪一项就明确标注。主任务验收须同时满足这三类要求。

主训练用VAL256选模，不以MICRO或训练回报选最终模型。替换保留模型时，安全成功数不减少、不安全数不增加、不新增严重碰撞任务；各类16图最多减少1个安全成功。对原始同协议全局Actor参照和当前最优模型均检查，避免多轮选模后累计遗忘。旧V4不冒充这个同协议参照。

## 6 消融实验设计

### 6.1 交付权重的推理对照

以下实验不更新网络，用来判断交付Actor在公共控制系统之上是否提供有效决策。统一保留APF、编队、安全层、投影规则及终端控制。

| 编号 | 对照变化 | 要回答的问题 |
|---|---|---|
| D0 | 使用冻结交付Actor，作为完整系统 | 完整闭环基准 |
| D1 | 去掉Actor，leader直接跟踪最终目标 | 收益是否主要来自原APF、编队或安全层；可与协议完全相同的纯APF对照复用 |
| D2 | 同结构、预先固定随机初始化且不训练的Actor | 改善是否来自学得权重，而非任意子目标加投影就能产生 |

三组记录安全完成和干预量。D2使用各训练种子对应的初始权重，不能另挑表现差的随机网络；主交付权重与其对应初始化配对。若完整Actor只增加了安全层负担或与随机策略相当，应如实报告。多次随机采样后挑最佳轨迹不属于同一确定性推理对照。

### 6.2 需要重新训练的组件消融

完整组F与每个变体分别从头训练，保持输入维度、隐藏层、动作语义与硬安全层一致。下面是最小完整实验矩阵；不能仅在已训练网络上临时遮挡输入，就宣称完成了对应重训消融。

| 编号 | 仅改变的因素 | 主要验证内容 |
|---|---|---|
| F | 完整方案 | 全部消融的共同参照，冻结最终配置 |
| A1 | 移除全局障碍token，保留边界、最终目标、位置与局部观察 | 全图障碍信息对凹墙、迷宫与远距离选路的贡献；Actor与训练Critic都采用相同遮挡 |
| A2 | 只保留当前局部帧，前15个历史帧置零 | 历史信息对停滞判断、延迟扰动和重复选择的贡献；训练与原生推理编码一致 |
| A3 | 去掉距离场势能进度项，其余奖励不动 | 最终任务稠密进度是否提高样本效率与任务成功，而非只提高回报数值 |
| A4 | 三线性插值改为最近邻查询，距离场、尺度和折扣不动 | 进度反馈连续性的单独贡献；与A3区分“有无进度”和“是否连续” |
| A5 | 仅将重访惩罚系数2设为0 | 对U形、死胡同和岔路绕圈的贡献；停滞和重复子目标成本保持原值 |
| A6 | 仅将近安全边界软惩罚设为0 | 在硬安全层保留时，是否改善裕度、干预比例和安全完成；终端不安全惩罚仍保留 |
| A7 | 取消新几何补充，使用预先固定TRAIN地图池 | 新地图覆盖对未见几何泛化的贡献；家族/扰动比例、复习比例与Replay淘汰规则不动 |

A1保持3340输入，对全局障碍的1280个特征置零，保留全图中边界6维与目标3维。A2也维持3340输入，避免同时改变参数量。输入变体在Python采样与MATLAB推理两端同步实施。

A5主要看重访与长期任务进度，A6主要看裕度与安全干预，不能只比较最终碰撞率。一次同时删除多个奖励项只能解释组合效果，不能替代上述单因素消融。

若需证明Critic动作再注入、训练探针或策略KL约束的贡献，可在基础矩阵之外分别增加单因素训练变体，重点报告探针误差、有效Actor更新、拒绝/回退次数及完整验证表现。它们不是Actor结构消融。

### 6.3 相同预算与多随机种子

每组至少3个独立训练种子，建议5个。按F加A1至A7计算，三种子方案共24个训练run，五种子方案共40个；推理对照不另算训练run。可预注册20261110、20261111、20261112为首组三种子；这些训练种子与环境测试种子分开管理。对应种子下，完整组和消融组采用相同随机初始化方案。

乙方在正式实验前提交并锁定总物理步预算B、优化步上限、梯度更新/数据比例、验证频率和选模规则。完整组与消融组使用同样预算及算力分配，记录实际物理步、唯一地图数、有效更新数与壁钟耗时。比较地图覆盖时保持家族和扰动分布一致；不能让完整组训练更久或额外调参。

提交安全完成率随累计训练物理步变化的学习曲线，各组在相同预算节点使用同一VAL评估，多种子给出均值与离散程度。奖励和损失曲线作为辅助诊断，不替代这条性能曲线。

完整方案预训练预算不能只计续训部分。对组件归因的正式实验，完整组与消融组均从共同随机初始化方案开始；不把成熟完整模型与从零训练的消融模型直接相比。

每组按相同、预注册的验证选择与训练稳定化规则处理本组历史；消融组不借用完整组权重回退。主模型的交付门槛不能用来删除性能较差的消融组。失败或中止的run也列入总表，记录实际预算、原因与能复现的最后状态，不只报告成功种子。

### 6.4 一次锁定与统计报告

开发期调整方案只使用TRAIN与VAL。最终测试前一次提交F、全部消融、全部训练种子的模型SHA面板，并指定唯一主交付模型。TEST512可对这个已封存面板统一运行；看过结果后不得更换主模型、补挑种子或追加有利变体。测试结果若用于新一轮改进，应更换新的封存测试集。

逐种子报告结果，并给出各组均值、标准差、最差种子和相对F的配对差值。训练种子与地图是两个变异来源，不能把3个种子乘512图当作1536张独立地图。多种子消融采用按训练种子和场景地图分层的配对重采样，保留同图配对关系；单一主模型对基线的检验按5.3执行。

主要消融比较预先指定安全完成率，并对F与各变体的多重比较校正。机制指标作为辅助证据。若区间跨0，应报告本基准下未检出明确贡献；不能要求每个消融都必须变差，也不能挑选seed、场景或截图制造结论。

## 7 专项验证与交付证据

### 7.1 工程检查

乙方至少提供以下可复验记录：全局编码与前向在Python和MATLAB的一致性；真实状态上的归一化动作最大绝对误差不超过5e-5；t=0接管和决策保持时钟；候选leader零规则规划调用；全部物理区间只归属一次转移；终点done与结果只计一次。

还需验证模型导出后重新载入、训练检查点恢复优化器与RNG、原生任务中途快照续跑，以及退步后回退与保留学习状态的行为。配置、源码或worker变化必须被哈希校验识别。审计记录能独立重建五机动力学、障碍与机间距离及边界判断。

### 7.2 防止奖励漏洞与弱场景被平均掩盖

在预先登记的TRAIN或VAL诊断场景检查：凹墙必须先远离欧氏终点才能绕出；反复选择容易到达却不推进任务的子目标；U形或岔路返回旧区域；贴障或贴边走捷径。记录最终任务进度、实际耗时、子目标序列、重访、安全裕度及任务结果。

奖励测试检查实际时间折扣、终端势能归零及折扣势能差的消去关系。不能在折扣小于1时，凭“未折扣闭环奖励应恰好等于0”来证明不会刷分；也不能仅凭公式宣称实际策略不会绕圈。须有原生闭环轨迹证据。
