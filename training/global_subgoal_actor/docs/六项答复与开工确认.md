# 六项书面答复与开工确认 · v1.1

本文件补齐任务书v1.0的开工缺项。工程目录为仓库内 `training/global_subgoal_actor`，commit以GitHub Release的目标commit及交付回执为准；检出后执行 `git rev-parse HEAD`记录。大资产Release标签：`schema6-training-handoff-20261115`。

## ① MATLAB R2026a

甲方实际核验环境是R2024a Windows x64，**没有R2026a实测记录**。源码采用现有MATLAB基础数值/文件/RandStream/JSON/MAT接口，静态检查未发现明确的R2026a移除API，但这不能替代设备侧核验。

推荐先使用已编译 `worker_windows/uav_rl_worker.exe`，另装R2024a Runtime。已有R2026a MATLAB保留，不必降级；R2026a不能被当作R2024a Runtime的替代。MathWorks明确要求Runtime主版本与编译版本匹配：[官方说明](https://www.mathworks.com/help/compiler/install-the-matlab-runtime.html)、[MathWorks支持答复](https://www.mathworks.com/matlabcentral/answers/2160625-which-version-of-matlab-runtime-is-required-compared-to-the-version-of-matlab-used-to-compile-with-m)。

如果要在R2026a运行源码或重编译，安装相应MATLAB Compiler并执行 `08_build_worker.ps1 -MatlabExe "实际R2026a的bin/matlab.exe路径"`。更换worker后记录其SHA，新建run，对同一已登记TRAIN/VAL小样本核验编码、动作、决策时钟、真实动力学与安全结果。新版worker配套R2026a Runtime。不要直接拿未经检查的新二进制续接旧run。

## ② 随机种子与run数

**先按三种子、24个正式训练run交付**：F和A1–A7，各用20261110、20261111、20261112。五种子40run不属于本轮最低交付，不自行扩增费用。推理对照D0/D1/D2不另算训练run。F与消融均从对应种子的随机初始化开始，不拿成熟F对比从零消融。

## ③ 局部规则脱困是否叠加全局路径

**不叠加leader全局路径。** 登记 `G1_LOCAL_RULE_ESCAPE_APF`，代码arm=`rule`，路由=`local_apf`。原生worker只有arm=`global_rule`启用规则leader全局路线；候选schema6启用`actor_global`，leader规则规划调用必须为0。公共终端从机对齐规划各组一致。

## ④ 旧V4模型

`assets/v4_initial.mat`，schema4、输入2048、旧局部偏移语义；作为 `G4_V4_ESCAPE_APF` 描述性历史对照，不是新schema6初始权重。V2为 `assets/v2_numeric.mat`。完整SHA在MANIFEST中，schema6的149/158另在 `assets/reference_models`。
