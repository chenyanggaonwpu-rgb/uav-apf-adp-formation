# 规划与参考余量：49 组合同图扫描

本轮只扫描冻结的 2.3.1 各向同性模式的 `pathClearance` / `desiredClear`，不改变高度策略、控制器或硬安全门限。竖直方向随这两项各向同性余量一起变化；本轮不是独立竖直余量实验。

- 规划候选：0.8、1.2、1.8、2.5、3.5、4.2、5.6 m。
- 参考候选：0.8、1.2、1.8、2.5、3.5、4.0、4.4 m。
- 完整笛卡尔积 49 组；每组复用同一批 seed 2001–2200，共 9800 个预定任务。
- 地图为前一轮保存 MAT 的逐字节复制，不重新生成、不筛图、不替换失败。
- 主要成功率分母 200；固定初始安全子集分母 157。43 个初始不安全地图仍进入主要分母。
- 成功要求完整原飞行/末端保持标准，规划可达数不能代替飞行成功数。

## 执行

在 F 盘项目根目录使用 `margin_grid49.py`：先在干净工作树提交脚本，`prepare --source-commit <完整提交号> --workers 6`，再 `validate`、`run`、`analyze`、`plot`、`deliver`。运行前冻结地图、任务清单、源码和参数，并保存 SHA-256。

`run --study <原目录>` 支持从各任务 MAT 继续。每个 worker 持有自己的地图分区；原始轨迹逐任务保存。异常保留原始记录并使本次统计不能通过完成门槛。

缓存从每张地图、每个规划余量的初始规划取得，在任何飞行之前冻结；禁止把上一架次的最终缓存交给下一架次。原模型已支持图缓存接口，本轮不修改数值核心。额外的缓存等价检查，以及基线 4.2/4.0 m 的全部 200 图非计时轨迹精确复现检查，防止缓存改变结局。

## 图表与结论范围

输出两个三维曲面（全部地图、初始安全子集）、精确热力图和飞行失败热力图，每图 PNG/PDF/FIG 及源 CSV。曲面各轴采用实际物理数值，显示全部 49 个实测点；网格面只连接样本，不拟合或声称验证了中间参数。

最高点和全部并列组合属于有限网格的探索性结果，不代表连续参数全局最优。未添加噪声/外扰实验，也没有新 seed 独立验证。任务成功不证明全程刚性 V 形或真实机体安全误差界。

平方命令加速度积分、路长和升降仅为代理指标。并发和共享缓存耗时不用于隔离初始规划或硬实时结论。全部结果、临时目录、日志和交付保存在 F 盘。
